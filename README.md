# Sistema de Citas para Barbería / Spa

Proyecto desarrollado como práctica de desarrollo web para gestionar citas, servicios y usuarios.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- MySQL

## Funcionalidades
- Registro de citas
- Gestión de servicios
- Validación de formularios
- Operaciones CRUD
- Organización de información en base de datos

## Estado del proyecto
En desarrollo / versión académica.
